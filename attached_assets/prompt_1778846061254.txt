You are a senior full-stack engineer, blockchain architect, and UX designer.
Build a production-grade decentralized voting and election platform that looks and feels like a modern, mainstream voting SaaS application (like Google Forms + SurveyMonkey + government voting portals), but is powered by Solana blockchain for transparency, auditability, and tamper-proof results.
The blockchain layer must be completely hidden from normal users.

---

 CORE PRODUCT VISION

This is NOT a crypto app.

It is a trusted digital election infrastructure system for:

- Schools
- Universities
- Churches
- Communities
- Companies
- DAOs
- Organizations
- Public/private polls

Users should experience it as a simple voting platform:

«Sign up → join organization → vote → see results»

 BLOCKCHAIN REQUIREMENTS (HIDDEN LAYER)

All votes must be stored on Solana:

- Each vote is written on-chain
- Use PDA to prevent duplicate votes:

- Election results derived from on-chain data
- Immutable audit trail

BUT:

- Users should never interact directly with blockchain
- Blockchain is only backend integrity layer
